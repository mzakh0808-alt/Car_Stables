# Инструкция по деплою Car Stables на Render (бесплатный план)

## Что нужно знать о бесплатном плане Render:

⚠️ **Важно:** Бесплатный план имеет ограничение - сервис "засыпает" через 15 минут неактивности. Первый запрос после пробуждения может занять **30-50 секунд**.

✅ **Что работает хорошо:**
- Persistent Disk (1 GB) - данные сохраняются
- SSL сертификаты - автоматически
- 750 часов работы в месяц (хватает для одного сервиса 24/7)

## Шаг 1: Регистрация и подключение GitHub

1. Зайдите на [render.com](https://render.com) и нажмите **Sign Up**
2. Зарегистрируйтесь (можно через GitHub)
3. После входа нажмите на **+ New** вверху справа
4. Выберите **Connect GitHub**
5. Разрешите доступ к вашему аккаунту GitHub

## Шаг 2: Создание веб-сервиса

### Способ А: Через Blueprint (автоматически - проще)

1. После подключения GitHub нажмите **+ New** → **Blueprint**
2. Найдите и выберите репозиторий `Car_Stables`
3. Render автоматически найдёт файл `render.yaml` и покажет настройки
4. Проверьте, что всё выглядит правильно:
   - Name: `car-stables`
   - Runtime: `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
5. Нажмите **Create Web Service**

### Способ Б: Ручная настройка (если Blueprint не сработал)

1. Нажмите **+ New** → **Web Service**
2. В разделе **Connect Repository** выберите `Car_Stables`
3. В разделе **Build & Deploy** заполните:
   - **Name:** `car-stables`
   - **Region:** Frankfurt (или любой ближе к вам)
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`

4. В разделе **Advanced**:
   - **Health Check Path:** `/api/health`

5. В разделе **Environment Variables** добавьте:
   - Key: `STATE_FILE`
   - Value: `/var/data/state.json`

6. В разделе **Persistent Disk** (очень важно!):
   - Нажмите **+ Add Disk**
   - **Name:** `car-stables-data`
   - **Mount Path:** `/var/data`
   - **Size:** `1 GB`
   - Нажмите **Add**

7. Нажмите **Create Web Service**

## Шаг 3: Ожидание деплоя

1. Render автоматически начнёт сборку и деплой
2. Это займет **2-5 минут**
3. Вы можете наблюдать за процессом в разделе **Logs**
4. Когда увидите "Deploy succeeded" - сервис готов!

## Шаг 4: Проверка работы

1. Нажмите на URL вашего сервиса (например, `https://car-stables.onrender.com`)
2. **Первый запуск может занять 30-50 секунд** - это нормально (сервис пробуждается)
3. Вы увидите экран загрузки с анимацией
4. После загрузки проверьте:
   - Главная страница открывается
   - Можно выбрать услуги
   - Форма записи работает
   - Чат доступен

## Шаг 5: Панель владельца

1. На сайте нажмите **Личный кабинет владельца** внизу страницы
2. Введите пароль: `car2024`
3. Вы увидите панель управления заявками и чатами

## Как избежать "засыпания" сервиса

Есть несколько способов:

### Вариант 1: Бесплатный пингер (рекомендуется)

1. Зайдите на [cron-job.org](https://cron-job.org)
2. Зарегистрируйтесь (бесплатно)
3. Создайте новую задачу:
   - **Title:** Car Stables Pinger
   - **URL:** ваш URL сервиса (например, `https://car-stables.onrender.com/api/health`)
   - **Execution:** Every 10 minutes
4. Сохраните

Теперь сервис будет получать запрос каждые 10 минут и не будет засыпать.

⚠️ **Важно:** Это расходует ваши 750 часов. Если сайт будет посещаться часто, пингер может превысить лимит.

### Вариант 2: Платный план ($7/мес)

Если сайт нужен для бизнеса, лучше перейти на платный план:
- Без spin-down (сервис всегда активен)
- Быстрее холодный старт
- Нет ограничений по времени работы

В Render Dashboard → ваш сервис → Settings → Change Plan → Starter ($7)

## Если что-то не работает

### Сервис не запускается
1. Проверьте **Logs** в Render Dashboard
2. Ищите ошибки в красном цвете
3. Убедитесь, что Persistent Disk подключён

### Данные не сохраняются
1. Проверьте, что Environment Variable `STATE_FILE` установлена в `/var/data/state.json`
2. Убедитесь, что Persistent Disk примонтирован в `/var/data`

### Сервис долго загружается
1. Это нормально для бесплатного плана при первом запуске
2. Добавьте пингер (см. выше) для более быстрой работы

### Хотите сбросить все данные
1. В Render Dashboard → ваш сервис → Disks
2. Удалите диск и создайте новый
3. Перезапустите сервис
